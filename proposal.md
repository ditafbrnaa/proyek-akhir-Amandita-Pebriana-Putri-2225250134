## 1. Latar Belakang
Evaluasi hasil belajar peserta didik merupakan bagian krusial dalam proses pembelajaran matematika. Seringkali, guru menghabiskan banyak waktu untuk melakukan rekapitulasi nilai secara manual, yang rentan terhadap kesalahan hitung. Oleh karena itu, diperlukan sebuah program berbasis Python yang modular dan otomatis untuk menghitung rata-rata, nilai minimum, maksimum, serta status ketuntasan siswa secara akurat.

## 2. Tujuan Proyek
- Membangun program Python modular untuk membaca, memvalidasi, dan menganalisis data nilai siswa.
- Menerapkan fungsi statistik dasar untuk evaluasi nilai kelas.
- Menyimpan hasil analisis secara otomatis ke dalam dokumen laporan teks.
