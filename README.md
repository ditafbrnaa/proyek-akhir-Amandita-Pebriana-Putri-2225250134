## Deskripsi Singkat
Program berbasis Python ini dirancang untuk membantu guru matematika dalam mengotomatisasi proses membaca data nilai siswa dari file teks, memvalidasi rentang nilai (0 - 100), menghitung statistik kelas (rata-rata, nilai minimum, maksimum), menentukan status ketuntasan siswa berdasarkan KKM, serta menyimpan laporan rekapitulasi secara rapi.

## Struktur Direktori
- `data/` : Berisi data mentah nilai siswa (`nilai_contoh.txt`)
- `src/`  : Berisi modul kode program utama (`main.py`, `data_io.py`, `analisis.py`)
- `tests/`: Berisi dokumen pengujian program (`test_case.md`)
- `proposal.md`: Proposal perancangan proyek
